# Research evidence boundary

`manuscript_metrics.json` records the values reported in the revised manuscript. It exists so the README chart and model card use one versioned source instead of scattered hard-coded numbers.

The manuscript PDF, raw DHS microdata, fitted research models, checkpoints, and reviewer correspondence are intentionally absent from the public repository. Add a manuscript/preprint only after the supervisor and journal policy permit it.

The public app loads `models/demo_transport_model.joblib`, which is trained entirely on deterministic synthetic data. Never present its predictions or metrics as NFHS-5 findings.
